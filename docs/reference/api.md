# API reference

Every HTTP route the application serves, from its OpenAPI document (generated by `scripts/gen_cli_reference.py`; CI fails when this page is stale). The live, interactive version is at `/docs` on any deployment. Authentication: `Authorization: Bearer ks-…` (or `x-api-key`) for tenant routes; the root admin token for `/v1/admin/*`.
